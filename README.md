# Aokigahara Portfolio

[Live demo](https://portfolio-ver2-bice.vercel.app) · [Repository](https://github.com/BlackMfgik/portfolio-ver2)

Personal developer portfolio focused on clear project presentation, performance-minded metadata, and responsive interaction design.

## Highlights

- Built with Next.js, React, TypeScript, and Tailwind CSS.
- Includes a custom ASCII canvas background and scroll-reveal animations.
- Implements Schema.org JSON-LD, an XML sitemap, and Open Graph / Twitter metadata for discoverability and social previews.
- Deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) after the development server starts.

## Commands

```bash
npm run build
npm run start
npm run lint
```
